# FESC Livewire / Blade

## Locations

- Layouts: `resources/views/layouts/`
- Auth pages: `resources/views/pages/auth/`
- Settings Livewire pages: `resources/views/pages/settings/`
- Components: `resources/views/components/`
- Styles: `resources/css/app.css` (accent teal `#0f4c5c`)

## Rules

1. UI copy in Spanish; code in English.
2. Prefer existing Flux/Livewire patterns from the starter kit.
3. No Bootstrap/React/Vue.
4. Keep first authenticated screens sober; no fake KPI dashboards.
5. Reuse layouts (`app`, `auth.split`) before creating new shells.
